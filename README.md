# Inventory-and-Billing-Management-System
# 🧾  Overview:
This is a full-stack web application designed to help small businesses manage their inventory, user accounts, and billing operations. Built using Flask (Python) for the backend and HTML templates for the frontend, it features both admin and user roles with separate dashboards.

# 👨‍💼 Admin Features:

1.Secure login with hardcoded credentials.
2.Add new inventory items with image upload.
3.View all inventory items and their stock levels.
4.Automatically tag stock as in stock, low stock, or out of stock.
5.View total users, total orders, and real-time inventory data.

# 🙋‍♂️ User Features:

1.Signup and login functionality.
2.Browse available inventory.
3.Purchase items (simulated payment).
4.Generate and download PDF invoices after purchase.
5.View personal order history.

# 🎯 Use Cases:

1.Small retail stores
2.School canteens
3.Simple warehouse systems
4.Billing systems with printable receipts
